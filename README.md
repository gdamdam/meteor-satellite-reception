# Meteor satellite reception

Two field reports on receiving Meteor M2-4 and M2-3 radio signals with a garden V dipole and SDR, then decoding them into weather images.

**[Read the illustrated reports](https://gdamdam.github.io/meteor-satellite-reception/).**

The scripts and technical source records are on the [source-and-evidence branch](https://github.com/gdamdam/meteor-satellite-reception/tree/source-and-evidence).
