# Meteor satellite reception

Static site for two Meteor weather-satellite observations from 23–24 September 2026. Open `index.html` for the overview, then the dated M2-4 and M2-3 reports.

The M2-4 report, `meteor-m2-4-2026-09-23.html`, explains the V-dipole setup, SDR recording, LRPT signal and image decoding. The M2-3 report, `meteor-m2-3-2026-09-24.html`, is a shorter, complete observation note. Each links directly to the other.

The exact receiving coordinates and local machine paths are intentionally absent from the public files. Both public videos show the recorded radio-signal panels and predicted sky tracks for a representative San Francisco point. The original I/Q recordings remain off-site; source records and reproducible figure scripts accompany the reports where available.

To preview locally, serve this directory with any static HTTP server and open `index.html`. Add `?cnt=0` to a page URL to skip GoatCounter for that visit.
